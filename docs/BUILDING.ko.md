# QuickLaunch 상세 가이드

macOS 메뉴 막대에서 실행되는 작은 앱 런처입니다. 다른 앱을 사용 중이어도 **Option(⌥) + 1·2·3·4·Q·W·E·R·A·S·D·F**로 열두 앱에 바로 접근합니다. 각 단축키는 고정되어 있으며, 각 행의 **앱 선택…** 버튼으로 연결할 앱만 지정합니다. 이미 실행 중인 앱은 앞으로 가져옵니다.

| 고정 단축키 | 새로 설치했을 때 기본 연결 |
| --- | --- |
| ⌥1 | Visual Studio Code |
| ⌥2 | Google Chrome |
| ⌥3 | Terminal |
| ⌥4 | Slack |
| ⌥Q | 앱 미지정 |
| ⌥W | 앱 미지정 |
| ⌥E | 앱 미지정 |
| ⌥R | 앱 미지정 |
| ⌥A | 앱 미지정 |
| ⌥S | 앱 미지정 |
| ⌥D | 앱 미지정 |
| ⌥F | 앱 미지정 |

앱을 지정하지 않은 키는 등록하거나 가로채지 않습니다. Q·W·E·R·A·S·D·F에도 앱을 연결하면 해당 단축키가 즉시 작동합니다. 기본 앱이 설치되지 않았다면 설정에 안내가 표시됩니다. **앱 선택…**으로 설치된 앱을 연결하세요.

## 창 열기 단축키 (v1.3.0)

**Option + ₩ / `**는 숫자 1 왼쪽의 물결(~) 표시가 있는 물리적 키입니다. Shift 없이 누르면 설정 창을 열거나 앞으로 가져오며, 앞에 열린 창에서 다시 누르면 숨깁니다. 최소화된 창도 복원합니다. 앱 선택 대화상자가 열려 있으면 숨기지 않습니다. 연결된 앱이 하나도 없어도 이 단축키는 등록됩니다. 등록 오류는 설정 창에서 별도로 표시하며 **단축키 다시 등록**으로 재시도할 수 있습니다.

## 실행

이전 버전이 실행 중이면 메뉴 막대에서 **QuickLaunch 종료**를 먼저 누르고 새 `QuickLaunch.app`으로 교체한 뒤 실행하세요. 실행 중인 앱에는 업데이트가 자동 적용되지 않습니다.

1. `dist/QuickLaunch.app`을 더블클릭합니다. 원하는 경우 `/Applications`로 복사해 실행하세요.
2. 실행할 때마다 설정 창이 열립니다. 숫자 1~4, Q/W/E/R, A/S/D/F를 각각 네 개씩 세 열로 표시합니다.
3. 각 행에서 **앱 선택…**으로 `.app` 응용 프로그램을 지정합니다. `/Applications` 밖의 앱도 선택할 수 있습니다.
4. **열기**로 연결을 확인한 다음 다른 앱에서 해당 단축키를 누릅니다. 예를 들어 ⌥Q는 Option 키를 누른 채 Q를 누릅니다.
5. 창을 닫아도 단축키는 유지됩니다. 화면 맨 위 메뉴 막대의 번개 아이콘 → **설정…**으로 다시 엽니다. 아이콘이 다른 항목에 가려져 보이지 않으면 `QuickLaunch.app`을 다시 더블클릭해 설정을 여세요.

앱 선택은 변경 즉시 `UserDefaults`에 저장되고 단축키도 다시 등록됩니다. 종료하려면 메뉴 막대 → **QuickLaunch 종료**를 누르세요. 로그인 시 자동 실행은 포함하지 않았습니다. 필요하면 macOS 시스템 설정 → 일반 → 로그인 항목에서 앱을 추가하세요.

기존 버전의 앱 연결은 **기존에 사용하던 단축키를 기준으로** 이어받습니다. 예를 들어 이전에 첫 번째 앱의 단축키를 ⌥R로 바꿨다면, 업데이트 후에도 그 앱은 ⌥R 행에 연결됩니다. 새로 생기거나 비게 된 키에는 앱을 임의로 채우지 않습니다. 저장 데이터의 중복 키는 첫 번째 유효 항목을 유지합니다.

Carbon `RegisterEventHotKey`를 사용하므로 키보드 감시나 손쉬운 사용 권한을 요청하지 않습니다. ANSI 숫자 행의 1~4 및 Q·W·E·R·A·S·D·F의 물리적 위치를 사용합니다. 다른 키보드 배열에서도 이 위치를 기준으로 동작하며 숫자 키패드는 별도입니다.

## 소스에서 빌드

요구 환경: **macOS 13 이상**, Xcode 또는 Swift 5.9 이상을 포함하는 Command Line Tools. 외부 라이브러리는 사용하지 않습니다.

이 폴더에서 실행합니다.

```bash
bash scripts/build-app.sh
open dist/QuickLaunch.app
```

스크립트는 release 실행 파일과 `Info.plist`를 포함한 앱 번들을 만들고 로컬 실행용 임시 서명을 합니다. `LSUIElement`가 켜져 있어 Dock 아이콘 없이 메뉴 막대에 표시됩니다. CPU 아키텍처는 빌드한 Mac을 따릅니다. 제공된 빌드는 Apple Silicon용이며 Intel Mac에서는 소스에서 다시 빌드하세요. Developer ID 서명과 공증은 포함하지 않습니다.

Xcode에서는 `Package.swift`를 열어 편집할 수 있습니다. 디버그 실행은 `swift run QuickLaunch`, 자동 테스트는 `swift test`입니다. 앱은 한 번만 실행하는 것이 좋습니다.

관리되는 실행 환경에서 `sandbox_apply: Operation not permitted`가 발생할 때에만 다음 명령으로 SwiftPM의 중첩 빌드 제한을 해제할 수 있습니다.

```bash
QUICKLAUNCH_DISABLE_SWIFTPM_SANDBOX=1 bash scripts/build-app.sh
```

## 충돌과 오류

- 단축키는 앱이 지정된 슬롯에만 등록합니다. 한 슬롯이 등록에 실패해도 다른 정상 슬롯은 계속 작동합니다.
- 충돌 오류(`eventHotKeyExistsErr`)는 **다른 앱이 이 단축키를 사용 중입니다**로 표시하고 다른 오류는 코드로 표시합니다. 다른 앱 또는 시스템의 단축키를 바꾼 뒤 **단축키 다시 등록**을 누르세요.
- 앱 파일이 이동되면 저장된 번들 ID로 다시 찾습니다. 찾지 못하면 **앱 선택…**으로 연결을 갱신하세요. 실행 실패도 안내 창으로 표시합니다.
- **기본값 복원**은 숫자 키 네 개를 위 표의 기본 앱에 연결하고 Q·W·E·R·A·S·D·F을 미지정 상태로 되돌린 뒤 저장·재등록합니다.
- 종료 시 등록한 단축키와 이벤트 핸들러를 해제합니다. 저장된 설정은 유지합니다.

## 검증

자동 테스트는 열두 슬롯의 초기 상태, 앱 경로·번들 ID 저장, 이전 네 슬롯의 이관, 단축키를 바꿨던 앱의 올바른 행 배치, 손상·중복·잘못된 저장 데이터 복구, 열두 Carbon 이벤트의 슬롯 매핑 및 미지정 키의 제외 조건을 확인합니다.

로그인된 macOS 화면에서 다음 시나리오로 실제 동작을 확인하세요.

1. 창 단축키를 눌러 열기·숨기기·다른 앱 뒤에서 앞으로 가져오기·최소화 복원·앱 선택 대화상자 유지가 동작하는지 확인합니다. 새 설정에서는 ⌥Q·⌥W·⌥E·⌥R이 미지정인지 확인합니다. 텍스트 입력 앱에서 이 키들이 QuickLaunch에 가로채이지 않는지 확인합니다.
2. 열두 행 모두 설치된 앱에 연결하고 다른 앱에서 열두 단축키를 각각 누릅니다. 닫힌 앱은 실행되고 열린 앱은 앞으로 와야 합니다.
3. 설정 창을 닫고도 단축키가 작동하는지 확인합니다. 앱을 다시 더블클릭해 설정을 열고, 종료·재실행 후 열두 연결이 유지되는지 확인합니다.
4. 이전 네 슬롯에서 키를 ⌥R·⌥Q·⌥1·⌥E처럼 바꿔 사용했다면 업데이트 후 해당 키 행에 기존 앱이 그대로 연결되는지 확인합니다.
5. `/Applications` 밖의 앱을 선택해 실행하고, 앱 이동 후 재연결 또는 번들 ID 검색을 확인합니다.
6. 첫 번째 QuickLaunch 실행 중 터미널에서 `dist/QuickLaunch.app/Contents/MacOS/QuickLaunch`를 실행해 두 번째 프로세스를 만듭니다. 두 번째에서 충돌 표시를 확인하고 첫 번째를 종료한 뒤 **단축키 다시 등록**으로 복구되는지 확인합니다. 테스트 후 두 번째도 종료합니다.
7. **기본값 복원** 후 숫자 키 기본 연결 및 Q·W·E·R·A·S·D·F 미지정 상태를 확인합니다.

자동 테스트와 빌드만으로 실제 앱 전환이나 모든 시스템 단축키 충돌을 검증할 수는 없습니다.

## 파일 구성

- `Sources/QuickLaunch/QuickLaunchApp.swift`: 메뉴 막대, 세 열의 설정 UI, 재실행 처리
- `Sources/QuickLaunch/HotKeyManager.swift`: 지정된 앱의 전역 단축키 등록·해제
- `Sources/QuickLaunch/LauncherStore.swift`: 앱 선택, 검색, 실행, 오류 상태
- `Sources/QuickLaunch/ShortcutKey.swift`: 열두 고정 키, Carbon 키 코드 및 이벤트 ID
- `Sources/QuickLaunch/SettingsRepository.swift`: 기본값, 이전 연결 이관, 저장 데이터 복구
- `Tests/QuickLaunchTests`: 설정·이관·이벤트 매핑 테스트
- `scripts/build-app.sh`: 실행 가능한 `.app` 생성
